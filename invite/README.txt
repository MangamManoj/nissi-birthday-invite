# Web invitation — GitHub Pages

This folder is the live WhatsApp invitation site.

## Local preview

Open `index.html` in a browser, or from the project root:

```powershell
npx --yes serve invite -p 5173
```

Then visit http://localhost:5173

## Deploy

1. Push this repo to GitHub.
2. Repo **Settings → Pages → Build and deployment → Source: GitHub Actions**.
3. Push to `main` (or run the **Deploy invitation to GitHub Pages** workflow).
4. Your link will be: `https://<username>.github.io/<repo>/`
