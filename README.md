# Nissita Mangam — First Birthday Invitation (GitHub Pages)

Live site is built from **`invite-v2/`** via GitHub Actions.

## After first push

1. Open the repo on GitHub → **Settings → Pages**
2. Under **Build and deployment**, set **Source** to **GitHub Actions**
3. Wait for the **Deploy invitation to GitHub Pages** workflow to finish (Actions tab)
4. Your invite URL will be:

`https://<your-username>.github.io/<repo-name>/`
